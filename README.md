2. Giải thích vì sao dùng toán tử lại tiết kiệm thời gian

- Toán tử filetype:pdf: Ép công cụ tìm kiếm chỉ trả về các định dạng file tài liệu chuẩn, loại bỏ các trang web chứa mã độc, bài viết quảng cáo hay rác.

- Toán tử site:edu.vn: Giới hạn phạm vi tìm kiếm trực tiếp trên các máy chủ giáo dục chính thống (các trường đại học, học viện), đảm bảo tài liệu chuẩn xác và đáng tin cậy.

- Toán tử trừ -site:tailieu.vn -site:doc123doc.net : Lọc bỏ ngay lập tức các trang web chia sẻ tài liệu kém chất lượng, yêu cầu nạp thẻ hoặc chèn link quảng cáo phiền toái.
